# House Script Format

Derived from `refernces/test Script.md` and `refernces/Videos Scripts.md`. This is the delivery format for the final scene-by-scene script.

## Scene table

Every beat is one row. Four columns, in this order:

| Column | Contains |
|---|---|
| `Time` | e.g. `0-3s`, `3-8s`, `41-46s` — contiguous, no gaps |
| `What we see` | Visual action, character expression, camera framing |
| `Dialogue` | `Speaker: "line"` in Hinglish where the house voice calls for it |
| `Phone screen` | The app screen or UI action shown, or `None` |

Example row:

| Time | What we see | Dialogue | Phone screen |
| --- | --- | --- | --- |
| 0-3s | Papa behind an empty counter, staring at his phone with wide eyes. | Papa: "2 minute mein meri dukaan online?! Mujhse nahi hoga!" | None |

## Beat pattern

- `0-3s` — hook. The visual and the spoken line land together.
- `3-8s`, `8-12s`, … — short beats, roughly 4–9 seconds each, each advancing the action.
- Final beat — the payoff, then the end card.
- Total duration is typically 20–35 seconds in the reference library.

## Outside the table

After the table, include:

- **CTA (voiceover over the end card, <duration>s):** one short line.
- **Caption:** one engaging line plus context.
- **Mandatory hashtags:** `#Meelte #LocalDiscovery #ShopLocal #Bengaluru #Ranchi #Gaya #SupportLocal #LocalBusiness`
- **Other hook lines to test:** 2–3 alternate spoken hooks.

## House voice

- Local shop owners, customers, neighbours, friends; everyday situations.
- Hinglish dialogue, short sentences, spoken not written.
- The phone screen is a character: show the actual tap path, not a generic "uses app".
- Warm, playful, non-corporate. No product pitch in the dialogue.

## Claim discipline

- The reference library warns that coin values, voucher partner, and redemption limits must match the live app and current terms. Never state them unless the user supplied them or they are verified.
- Prices, discounts, and deadlines come only from the user or the improved prompt.
